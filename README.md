# Liquid Home

Самостоятельный Android-лаунчер с оформлением в стиле стекла. Версия исходников: 8.5. Не зависит от Jarvis, не требует root и не заменяет прошивку телефона.

- Рабочие столы, поиск и библиотека приложений.
- Стеклянные значки и папки; создание папки перетаскиванием.
- Редактор с удалением значков, переносом виджетов и страницами.
- Часы, музыкальная медиасессия и управление совместимым V2RayTun.
- Локальное отображение уведомлений через плавающий остров; системная шторка остаётся системной.
- Импорт раскладки из подготовленного локального JSON, без доступа к закрытой базе штатного лаунчера.

## Сборка Android

Требуются JDK 17, Android SDK 35 и Gradle 8.9. Откройте корень проекта в Android Studio либо выполните `gradle :android:app:assembleDebug`. Путь к SDK задайте через `ANDROID_HOME` или локальный `local.properties` (он исключён из Git).

APK появится в `android/app/build/outputs/apk/debug/`. Используется отдельная локальная debug-подпись. Она не совпадает с подписью установленной личной сборки: не удаляйте рабочее приложение ради установки экспериментальной сборки. Личные ключи подписи и готовые APK не включены.

## Данные и зависимости

В репозитории нет личных адресов сервера, API-ключей, токенов, сертификатов, резервных копий телефона, контактов, журналов диалогов или пользовательской раскладки. Локальные конфигурации, модели, сборки и ключи исключены через `.gitignore`. Перед публикацией собственных изменений запускайте `python tools/check_public_tree.py`.

Лицензии сторонних библиотек и моделей определяются их авторами. Они не становятся частью прав на исходники этого проекта.

## Настройка и разрешения

Назначение домашним экраном выполняется в настройках Android. Доступ к уведомлениям нужен для музыки и острова; разрешение отображения поверх приложений — для острова. Без этих разрешений соответствующие функции недоступны. Приложение не запрашивает разрешение INTERNET.

По умолчанию используются системные шрифты. При наличии прав на распространение или использование собственных шрифтов можно локально добавить `fonts/ui-regular.ttf`, `fonts/ui-medium.ttf`, `fonts/ui-light.ttf` в каталог assets. Шрифты San Francisco не включены.

Личные обои не включены. Возврат к штатному лаунчеру открывает настройки домашнего экрана; восстановление личных обоев выполняется средствами Android. Готовые личные резервные копии и сценарии отката конкретного телефона в этот проект не перенесены.

## Структура

`android/app/src/main/java/ru/local/glasshome/` — интерфейс и логика; `Home.java` — рабочие столы и редактор, `MiuiImport.java` — локальный импорт, `MediaAccess.java` и `Island.java` — музыка и уведомления.
